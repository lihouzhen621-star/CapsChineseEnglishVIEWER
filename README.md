# Input Glass

## 项目定位

Input Glass 不追求复杂的设置页面或大量附加功能。

它只专注于一件事：

通过轻盈、直观且具有动态美感的方式，让用户随时知道自己当前正在使用哪一种输入状态。

## 项目介绍

Input Glass 是一款用于显示当前输入状态的桌面悬浮工具。

软件会读取计算机当前真实的输入法与 Caps Lock 状态，通过悬浮在屏幕顶层的液态玻璃面板，清晰显示英文、中文或大写输入模式。

它适合经常需要切换中英文、进行文字创作、编程、办公或全屏工作的用户，能够减少输入法状态不明确造成的误输入。

## 状态显示

| 当前状态 | 显示标识 | 主题颜色 | 状态说明 |
|---|---:|---|---|
| 英文输入 | **EN** | 蓝色 | English input source |
| 中文输入 | **中** | 红色 | Chinese input source |
| 大写锁定 | **A** | 绿色 | Caps Lock active |

Caps Lock 开启时，大写状态会优先显示；关闭后自动恢复当前中英文输入状态。

## 核心功能

- 实时检测当前中英文输入状态。
- 支持微软拼音使用 `Shift` 切换中英文后的状态变化。
- 自动检测 Caps Lock，大写模式显示绿色 **A**。
- 始终置于屏幕最上层，不会被普通窗口覆盖。
- 面板可以使用鼠标自由拖动。
- 支持鼠标滚轮缩放，范围限制为 62%～125%。
- 最大缩放具有边界保护，避免内容变形或超出面板。
- 内置小型关闭按钮，无须通过任务管理器退出。
- 自动记忆上次使用的面板位置和缩放比例。
- 便携运行，无须安装，也无须预装 Python。
- 不连接网络、不上传数据、不包含账户系统和遥测功能。

## Liquid Glass UI 设计

Input Glass 的视觉设计参考 Apple Liquid Glass 设计语言，强调轻盈、通透、柔和与动态反馈，而不是传统的静态磨砂玻璃效果。

### 流体透明材质

主面板采用多层半透明玻璃结构，通过背景采样、柔化、环境色吸收和低透明度叠加，让桌面颜色自然渗透到玻璃内部。

玻璃不会表现为单纯的白色矩形，而是会随着桌面背景产生不同的色彩倾向。

### 液态流动效果

彩色状态徽章内部包含持续运动的柔和色彩层，通过渐变、光影位移和形态变化模拟液体缓慢流动。

主玻璃背景也具有独立的流动动画，但速度比彩色徽章更慢，形成前后两层不同节奏的动态效果。

### 柔和高光与折射

面板边缘使用低透明度高光模拟玻璃表面的镜面反射，并通过柔化处理避免出现生硬的白色描边。

内部背景会产生轻微的模糊、位移和折射感，使悬浮面板能够自然融入不同桌面环境。

### 多层悬浮深度

界面采用轻量化的多层阴影建立空间层次：

- 主面板与桌面背景保持清晰分离。
- 彩色徽章具有独立的悬浮深度。
- 高光、暗部和环境颜色共同塑造玻璃厚度。
- 避免使用环绕整个卡片的厚重黑色阴影。

### 动态交互反馈

拖动面板时，液态内容会根据移动速度产生柔和偏移，并通过弹性动画逐渐回到稳定状态。

这种反馈让面板具有一定的重量感和流动感，同时不会影响正常操作。

## 界面布局

面板采用紧凑的横向信息布局：

- 左侧为大型彩色状态徽章。
- 右侧为当前输入模式名称。
- 模式名称下方显示简短英文状态说明。
- 右上角提供低存在感的关闭按钮。
- 不显示多余标题、操作提示或工具栏。

整体排版保持视觉重心居中，在不同缩放比例下维持相同的内容比例和留白关系。

## 交互方式

| 操作 | 功能 |
|---|---|
| 按住面板并移动鼠标 | 拖动悬浮面板 |
| 鼠标指向面板并滚动滚轮 | 调整显示大小 |
| 点击右上角关闭按钮 | 退出 Input Glass |
| 切换输入法或按下 Caps Lock | 自动更新状态 |

## 使用场景

Input Glass 适合以下使用场景：

- 中英文频繁切换的文字创作。
- 编程、终端命令和代码输入。
- 全屏办公、演示与视频录制。
- 使用隐藏任务栏或极简桌面环境。
- 需要快速确认 Caps Lock 状态的键盘用户。
- 输入法状态提示不明显的高分辨率显示器。

## 隐私说明

Input Glass 只在本机读取必要的输入状态，包括：

- 当前前台窗口。
- 当前输入法状态。
- Caps Lock 状态。
- 软件自身的位置和缩放设置。

软件不会读取用户输入的文字内容，不会记录键盘输入，不会连接服务器，也不会向网络发送任何数据。

## 运行方式

Windows 用户可以从 GitHub Releases 下载：

```text
InputGlass-Windows-x64.exe
```

下载后双击即可运行，不需要安装。删除 EXE 即可移除软件。


## 平台说明

当前 V1 版本以 Windows 10/11 为主要发布平台。
