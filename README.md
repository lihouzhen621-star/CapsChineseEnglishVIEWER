Input Glass - Windows x64
============================

中文说明
--------
1. 本软件为便携版，无需安装，也不需要安装 Python。
2. 双击 InputGlass-Windows-x64.exe 即可运行。
3. 在面板上拖动鼠标可以移动；滚轮可以缩放；右上角 × 可以退出。
4. 如果 Windows SmartScreen 弹出提示，请先确认文件来自官方 GitHub Release，并核对 SHA256。
5. 删除 EXE 即可移除软件。设置文件位于 %APPDATA%\InputGlass。

English
-------
1. This is a portable app. No installation or Python runtime is required.
2. Double-click InputGlass-Windows-x64.exe to run it.
3. Drag the panel to move it, use the mouse wheel to resize it, and click × to quit.
4. If SmartScreen appears, verify the official GitHub Release source and SHA256 first.
5. Delete the EXE to remove the app. Settings are stored under %APPDATA%\InputGlass.
